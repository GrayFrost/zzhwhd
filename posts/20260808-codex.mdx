## 前言
在几个月前，claude code如日中天。我当然也趋之若鹜。可当我实际入手之后，才发现困难重重。  

由于anthropic对国内没啥好脸色，导致大陆的用户想使用这一顶尖AI模型非常困难。首先你需要祈祷自己注册的claude的账号不会被封；其次你直接使用claude code客户端时可不会一帆风顺，往往需要使用cc-switch等切换工具；最后是claude的费用贵得一塌糊涂，简单问几个问题做几个任务一个月的token就用完了。  

所以在尝试了一个月的claude code之后，我决定寻找替代品。

我在使用claude code的时间里，还同时尝试了很多AI模型：deepseek、minimax等。我发现能和claude code掰手腕的，也就是chatgpt。原因如下：
- 模型先进，处理代码的能力同样第一梯队
- 有好用的agent
- 不会随便封杀大陆用户，对大陆用户较友好，这也是我看中的一点。

很幸运，世界上还有claude code的替代品，它就是openai公司推出的Codex。  
 > 备注：在我最开始用Codex的时候，Codex最新的模型是gpt5.3，而到了写文章时，已经是gpt5.6了。而且客户端已经统一改名叫ChatGPT了。

而我从4月份到今天，使用Codex已经连续使用了四个月了。

## 是什么
**Codex**说的简单点，就是agent客户端。它把agent的工作流程都在代码里封装好，然后再通过底层调用模型来处理用户对其分发的各种人任务。

因为是关于Codex的介绍，所以会介绍Codex的基本使用。至于Cluade Code，路边一条。

关于Agent，用过AI的人都知道，其实就是关于某一特殊领域的知识专家助手，你给他关于某一方面的人物或问题，它就能帮你解答对应专业领域的问题。比如写作agent，专门帮你解决写作问题；医学agent，帮你解答医学上的问题。
再精细点划分，我们可以自定义一些公众号agent，小红书agent等等。

而codex，则是agent的智能集合体，你给他派发一个任务，它就会去搜索对应任务要如何实现，帮你处理。

## 怎么用

Codex具有四种运行模式：
- Cli 
- App
- Web
- IDE

我最常使用的就是桌面App模式，偶尔使用IDE和Cli的模式，Web网页模式完全没用过。

### 安装

### App
App模式当然就是下载桌面客户端，直接在官网下载，然后登录自己的ChatGPT账号即可。

### IDE
因为我常年使用的代码编辑器是VSCode，所以只需在VSCode的插件栏里搜索一下Codex的插件安装，然后登录ChatGPT账号即可。

![](/images/20260808codex/2.png)

### Cli
```bash
# npm 安装
npm install -g @openai/codex

# Homebrew 安装（macOS）
brew install --cask codex
```
目前我在window系统上操作，就只使用了npm install的方式。安装完，在控制台尝试打一下命令：
```bash 
codex --version
```
如果能正常显示`codex-cli 对应版本号`，说明安装成功。

### 使用
当我使用客户端时，既可以像在平时和普通ai客户端使用一样做简单的问答，也可以按项目的形式对自己的人物需求做管理。你可以把自己当成一个项目经理，每个目录是一个项目，在一个目录下管理你的专属项目。比如我想写小红书推文，我们就专门建一个项目来管理小红书内容；想做游戏，就把游戏开发项目单独一个目录。  

而Codex就是专门帮你干活的人，它会根据项目的上下文，单独隔离帮你处理不同项目之间的需求。因此我建议每次做需求都单独开一个目录。

### Agents.md

在做产品之前，我们往往需要知道这个产品的定位和未来规划。拿开发游戏来说，我需要使用什么游戏引擎，需要发布在哪些平台，面向的用户群体是谁等等，我们都需要考虑好。我们可以在开一个项目之初，就开始和Codex沟通，让它明确地知道你想要干什么。

在它清楚的知道你要干什么之后，你就可以要求它在目录下创建一个Agents.md文件，这个文件就是用来约束Codex的。你可以把这份文件理解成是一个指导文件。AI并没有想象中的聪明，它就像是一个出入社会，记性和动手能力稍微强点的大学生，它需要一份入职指导。

有了这份入职指导，它就知道它可以干什么，不能干什么，可以用哪些能力来干。

比如我们做开发时，往往有环境隔离的需求。一般我们在处理环境时，都是在代码里有env相关的环境来写配置，我们就可以在开发之初，就在agents.md里规定，env相关的文件不要上传到代码仓库。比如在做数据库查询时，我们就可以在agents.md里限制ai绝对不能进行删库操作等。

### 指令
在Codex客户端输入对话框里，我们通过`/`这个符号来唤起指令。指令有客户端自带的，也有我们安装了skills之后添加的。
我通常最常用的就是status和plan mode这两个指令。
`/status`可以查询当前我还有多少token用量，`/plan mode`则像是在和Codex沟通需求，在它和我们沟通了几轮之后，它会为我们制定一个计划表，按表上的内容逐步执行。
